First release of **Rabbit Ears**, a 90s TV set for OnionOS on the Miyoo Mini and Mini Plus.

Put videos in `Media/TV` and flip through them like cable channels: a burst of snow between channels, a green channel number in the corner, and every channel always "on the air" so you tune in mid-show based on the clock.

- A video file is a channel that loops; a folder of videos is a channel that airs its episodes in order
- Name a file or folder `07 Something` to pick its channel number
- Channel guide (Select), display info with time left (A), previous channel (B), CRT power on/off (Menu)
- Plays through Onion's built-in FFplay, so there's nothing else to install
- Retunes to what's on now after the device wakes from sleep

**Files**

- `RabbitEars-v1.0.0-OnionOS.zip` — copy its `App` and `Media` folders to the SD card root (or install from Mixtape)
- `vhsify` — converts videos on Linux/macOS (needs ffmpeg 4.4+) into small 320×240 files with a VHS look: `./vhsify --mirror ~/Videos/TV -o /media/$USER/<card>/Media/TV`
- `vhsify-pi-docker.zip` — the same converter as a drop-folder Docker service for a Raspberry Pi
